## Observed results

Fresh clean-source Docker captures produced 72 board-control cases and 57 bootstrap cases. Fresh interpreter replay passed both control tests (including rejection of a changed `restore_ack.device_observed` receipt) and the bootstrap replay: **3 tests passed**. All 72 control request, response and boundary-call records are identical to 10.1.17. Bootstrap differs only in five version-bearing responses: health, discovery in enabled/disabled/undecided modes, and version. Every other bootstrap case is identical. This is execution against 10.1.20 source, not a version substitution in old response fixtures.

The corpus includes original-revision conditional page/collection/schedule/default edits, stale 412, clear/null/omission behavior, authentication setup/session behavior, concrete split-flap/LED/array controls, acknowledged/unchanged/UI/preview/held/refused/throttled/superseded/partial/error outcomes, restore and page selection, sparse scalar PATCH and non-atomic missing-default failure. See the actual case records for scope.

Message receipts retain `sent`, concrete `board_id`, `characters`, `text`, `expires_at`, `reason`, `silenced`, `held`. Held 202 means accepted for later. Restore retains `board_id`, `page_id`, `sent`, `reason`, `device_observed=false`. Selection may persist while `sent=false`; the active-page envelope retains `error`/`warnings`. Conditional default GET uses query `board_id`; PUT uses body `board_id`, `page_id`, `expected_revision`. Tokens remain conservatively shared across boards. Scalar PATCH has no revision protocol and must not substitute for conditional default PUT or imply atomic scalar/default edits.

## Source comparison and substrate

The exact SHA-256 bindings, corpus bytes and harness bytes are in [manifest.json](../../Fixtures/contracts/10.1.20/manifest.json). All captured bootstrap source-file digests remain unchanged. Controls change `src/main.py` and `src/plugins/registry.py`; other captured source files are unchanged. Additional changed implementation files are `src/pages/service.py` and `src/plugins/base.py`.

The implementation changes pass display identity into page context and render fingerprints, and serve a bounded recent cached provider result when fetches time out or are quarantined (`max(2 * interval, interval + 300)` seconds). Those provider/cache semantics are **not tested** by the deterministic provider boundary in this corpus. No broad compatibility conclusion follows from unchanged handler receipts.

`requirements.txt` and `outputs.lock.json` are byte-identical between the two commits (hashes recorded in manifest), so the existing immutable dependency/seed image `sha256:79ecc5613dec30c8d46ce5533083e1093a85b2295556e7de3111bf63032ef530` was reused with a separate clean 10.1.20 archive. No backend worktree source was mounted.

## Reproduction

Run `python3 Fixtures/contracts/10.1.20/verify.py` for local artifact integrity and exact old/new case comparison, including a changed-receipt negative check. These additive artifacts are not registered in the current snapshot integrity checker yet.

For backend replay, prepare a fresh source directory with:

```sh
python3 scripts/contract-backend.py prepare --repo /path/to/FiestaBoard --commit ff2415c4a646b55510f6f633c78915cdc9c333f2 --destination /tmp/fb-10.1.20-source
mkdir /tmp/fb-10.1.20-source/data
```

Use the existing fenced Docker runner pattern from [the integration runbook](../../Tests/Integration/README.md), mounting that source at `/app` read-only, `Fixtures/contracts/10.1.20` at `/contract-tests` read-only and `Fixtures/contracts` at `/contract-fixtures` read-only. Set `PYTHONDONTWRITEBYTECODE=1`, `PYTHONPATH=/app`, `HOME=/tmp`, `FIESTABOARD_DATA_DIR=/tmp/contract-data` and `FIESTABOARD_OUTPUT_SEED_DIR=/opt/fiestaboard/seed/outputs`. Use `--network none --read-only --cap-drop ALL --security-opt no-new-privileges --tmpfs /tmp:rw,nosuid,size=1g --tmpfs /app/data:rw,nosuid,size=64m --workdir /app --entrypoint python` with the immutable image above. Run `-m pytest -q -p no:cacheprovider /contract-tests/test_current_board_controls.py /contract-tests/test_current_contracts.py`. Capture scripts were copied from existing integration harnesses with only SOURCE, VERSION and fixture directory changed; they import backend code exclusively inside Docker.

## Limits

Temporary stores only; no ASGI lifespan, initialize/run workers, real output clients, actual provider fetches, user config, credentials or hardware. Final driver render/read-refresh, provider context and clock boundaries are deterministic. `sent=true` is simulated output-boundary acceptance; no physical output is observed. Hardware/model detection is stubbed in the bootstrap version case. No live-host credentials, mutation, ingress, deployment topology, OAuth or release readiness are established. Source pinning and the new corpus support review of a bounded exact-version candidate only.
